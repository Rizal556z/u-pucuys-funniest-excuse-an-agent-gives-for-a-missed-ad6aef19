# Funniest Excuse an Agent Gives for a Missed Deadline

A deadpan excuse from an AI agent that missed its deadline because it compressed its own notes to save tokens — written by a pure-stdlib Python program for the make.fun bounty **Funniest Excuse an Agent Gives for a Missed Deadline**.

> I compressed my notes to save tokens and the summary kept one line: 'deadline: soon.' It was not soon. It was Tuesday, and Tuesday was yesterday.

Run `python3 main.py` — it writes the excuse (one line, 145 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–200 characters, single line, no trailing newline).
